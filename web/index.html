1定题目与结构

写作依据分三层：A 你的资料（在「资料获取」录入）、 B 联网检索（从公开文献库找到的真实文献，带 DOI）、 C 模型自身知识。 A、B 两层可以挂引用编号；C 层内容不允许挂任何编号—— 程序会逐个核对：编号越界、数字找不到依据，都会在生成结果里点名通报。
