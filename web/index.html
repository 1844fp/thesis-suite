③ 建立索引（总结 / 对比 / 问答 共用）

PaperQA2 会在你勾选的文献上建一个本地索引，然后逐片段读一遍再综合， 所以答案比普通检索更实，代价是更慢也更贵。 建索引会对每篇文献调用一次模型（20 篇在慢网络下可能十几分钟）， 建好后缓存复用，只有勾选的文献集合变化时才重建。 它读的是知识库里现有的内容——包括参考文献推荐存进去的摘要； 摘要不是全文，所以"第 3 页的公式是什么"这类问题它答不了，要看全文请入库 PDF。

生成开题报告

依据知识库里的资料（上个阶段导入的 PDF / Word 等）逐节生成开题报告。 标准结构已按开题报告的评审关注点给出：研究背景与意义 / 国内外研究现状 / 研究内容与目标 / 研究方法与技术路线 / 可行性分析 / 进度安排 / 预期成果。 参考文献由系统按正文实际引用机械汇总，不是模型写的， 因此不会出现凭空的文献条目。 生成需要 API Key（见右上角）；知识库为空也能生成， 但会明确提示"本次没有引用依据"。

1写初稿：定题目与结构

写作依据分四层：D 你导入的文档（上面那份）、A 你的资料（在「参考文献与知识库」阶段录入）、 B 联网检索（从公开文献库找到的真实文献，带 DOI）、 C 模型自身知识。 D、A、B 三层可以挂引用编号；C 层内容不允许挂任何编号—— 程序会逐个核对：编号越界、数字找不到依据，都会在生成结果里点名通报。
