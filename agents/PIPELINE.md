# 六板块流水线：每一步交给谁、为什么这么排

这篇说明**为什么是这六步、顺序为什么不能换**。它的用处不是介绍功能，
而是解释每道工序在防什么错误——一个顺序错了就会白干的流水线。

```
① 定题目 → ② 开题报告 → ③ 写初稿 → ④ 修改与评估 → ⑤ 查重与降AIGC → ⑥ 答辩
```

---

## ① 定题目

**产出**：一个能写下去的题 + 一个可检索的本地知识库。

**防的错误**：题太大（写成综述）、题没材料（写到一半发现无据可依）。

关键在"能写下去"这三个字。出题看似是起点，实际是**用现有材料反推题目**：
知识库里有哪方面的资料，题目就该往那个方向收。所以知识库不是附属功能，
它是出题阶段的一部分。

> 相关智能体：`topic`（generate / outline）+ 本地 RAG 知识库

## ② 开题报告

**产出**：结构化的证据池（每条带出处、可核验）+ 参考文献表。

**防的错误**：**编造参考文献**。这是最致命也最难自查的错误——条目格式完全正常，
作者、年份、卷期页一应俱全，作者本人无从判断。

所以这一步不只是"收集资料"，而是**把每条资料的出处固定下来**，
后面所有写作都从这份证据池取引用，不允许写作时现编。

> 相关智能体：`gather`（import / extract / verify / export）
> 能力层对应：`gather:literature`、`rag:retrieve`、`verify:external`

## ③ 写初稿

**产出**：逐章正文 + 依据覆盖度报告。

**防的错误**：写了但没依据（"看起来像论文"的空话）。

三层依据来源，按可靠性排序：

| 层 | 来源 | 说明 |
|---|---|---|
| A | 作者自己的资料 / 知识库 | 最可靠，可直接引用 |
| B | 联网检索到的真实文献 | 带 DOI / 可核验 |
| C | 模型自身知识 | **只用于行文，不当依据** |

写作时每个数字都要能追回证据池；引用角标只能用池子里真实存在的编号。
写不出依据的地方会如实标出，而不是拿模型知识顶上。

> 相关智能体：`writer`（draft / export）
> 能力层对应：`writer:plan`、`writer:draft`、`writer:conclude`、`writer:references`

## ④ 修改与评估

**产出**：问题清单 + 审稿意见书 + 按意见定点改写后的新版本。

**防的错误**：改了但没修好（"看起来改了"）。

这一阶段有三条纪律：

1. **评分由检查结果机械推导**，不是模型打的印象分——否则同一份稿两次评分不一样，
   作者无从判断自己有没有进步。
2. **只改被点名的句子**，其余保持原样。整段重写会让作者无法核对"到底改了什么"，
   而且很容易把原本有依据的句子改丢。
3. **材料不足时如实说"无法解决"**，不硬改。

> 相关智能体：`review`（check / verify_refs / opinion / template）+ `writer`（revise）
> 能力层对应：`fixer`、`format:apply`、`writer:polish`、`writer:rewrite`

## ⑤ 查重与降 AIGC 率

**产出**：风险自查报告 + （可选）改写稿。

**防的错误**：**误以为查过了**。这是整条流水线上最危险的一步——
一个"看起来很专业的百分比"比不做更坏，因为它给作者一个虚假的安全感。

所以这一步把能做的和不能做的分得很清：

**能查的（本机可做）**
* 同一份稿子里两段高度雷同
* 参考文献能否在公开文献库里对上真实记录

**查不了的（必须用学校系统）**
* 与已发表文献、网络内容、往届论文的重复

AIGC 同理：AI 味指数是**本地风格启发式代理**，不是知网 / 维普 / PaperPass
那类检测器的输出，**两者数值不可互相换算**。优化的是已被公开研究反复验证
与检测器输出相关的风格信号，但这**不构成对任何具体检测器结果的承诺**。

> 相关智能体：`integrity`（duplication / aigc_score / aigc_reduce）
> 能力层对应：`aigc-reducer` 的 11 项指标 + 29 条规则 + 保真校验闭环

## ⑥ 答辩

**产出**：答辩稿（陈述 8~10 分钟 + 预计提问与应答）+ 演示幻灯片。

**防的错误**：**答辩时被问住**。

所以这一步有两个设计：

* 预计提问覆盖**五类最难的问题**：研究问题与创新点、方法可靠性、数据来源、
  结论的适用边界、**与你结论相左的文献**。
* 幻灯片每条要点**不超过 25 字**。演示稿不是文档——长句子投到屏幕上没人读。
* 材料不足以支撑某一页时会标注"材料不足"，而不是编。

> 相关智能体：`defense`（script / slides / pptx / html）

## 顺序为什么不能换

| 若把…提前 | 后果 |
|---|---|
| 先写初稿，后定题目 | 写到第三章发现题目要的材料没有，整章作废 |
| 先写初稿，后建证据池 | 引用只能现编，而编造的参考文献**极难自查** |
| 先改写，后评估 | 不知道改什么、也不知道改完有没有变好 |
| 先降 AIGC，后评估 | 风格被改过一遍，评估看到的不再是作者的真实文本 |
| 答辩材料先做 | 稿件还在变，讲稿与幻灯片全部要重做 |

**一句话**：每一步都为下一步**减少不确定性**。跳过任何一步，
不确定性都会在最后一步集中爆发——而那时候改的成本最高。

## 与另一套（thesis-agents）的关系

`thesis-agents` 是能力层（13 个智能体，能力①②③⑤⑥），按**能力**组织；
本站是板块层（6 个智能体），按**使用者要走的流程**组织。

同一件事在两个层面上的名字不同，是**有意的**：
能力层要便于单独测试与复用，板块层要便于人上手。
把 19 个能力名直接摆给使用者，他会不知道从哪开始。
