# 论文选题助手（thesis-topic-helper）

按学科/专业**一次生成 5 个以上随机论文题目**，每个题目都自带一份可以直接拿去开题讨论的**简报**：
研究背景 → 研究问题 → 理论框架 → 方法 → 数据来源 → 创新点 → 可行性 → 风险，
再加一段有观点的**文献短评**（代表性文献 + 贡献 + 局限 + 研究缺口）。

提供两种用法，同一个内核：

| 用法 | 入口 | 适合 |
| --- | --- | --- |
| **网页界面** | `run.cmd`（双击即可） | 日常选题、边看边换、一键导出 |
| **命令行** | `run.cmd gen -d 教育学 -n 8` | 批量出题、导出文件、被其他程序调用 |

---

## 一、快速开始

```bat
:: 双击 run.cmd，或：
run.cmd
```

浏览器会自动打开 `http://127.0.0.1:8848/`。默认已经**自动借用**
`..\thesis-assistant\.env` 里配好的 DeepSeek Key，所以通常不需要任何配置。

三种操作路径：

1. **要马上看到效果**：填学科 → 点「生成选题」（无 Key 时自动走离线模式）。
2. **要用自己的 Key**：右上角「设置」→ 填 Base URL / API Key / 模型名 → 保存（写回 `.env`）。
3. **要在命令行里出题**：

```bat
run.cmd gen -d 临床医学 --type 实证研究 --methodology 倾向性评分匹配 -n 8
run.cmd offline -d 艺术与设计 -n 10 --out exports\设计选题.md
run.cmd disciplines
run.cmd doctor
```

## 二、两种生成模式

### 1. 大模型模式（推荐）

调用任意 **OpenAI 兼容接口**，题目更贴学科、文献短评更有观点。
兼容 DeepSeek / 智谱 GLM / 通义千问 / Kimi / OpenAI / 本地 Ollama。

流程上做了几件工程上的事，避免"等一分钟换来一个报错"：

- **分批生成**：数量 > 8 时自动拆成多批，避免单次输出被 `max_tokens` 截断；
- **容错解析**：模型返回代码块、夹带解释、JSON 被截断，都能救回来（截断时保住已完成的题目）；
- **兜底字段**：某个题目漏写简报时，自动按题目补一份占位简报并在界面上标注；
- **自动补数**：第一批题目不够时自动再补一轮，尽量凑满你要求数量；
- **补简报**：个别题目是被截断后救回来的（题目在、简报没写完）时，只针对这几道再补一次，
  不会把已经定好的题目整批换掉；
- **去重**：换一批时会把已有题目作为"禁止重复"清单传给模型。

### 2. 离线知识库模式（不需要 Key）

内置 12 个学科的知识库（热点 × 研究对象 × 理论 × 方法 × 数据来源），
按模板随机组合出题，秒出结果、完全离线、可用随机种子复现。

> ⚠️ 离线模式的**文献条目是占位引用**（一律标注「待核实」），
> 题目骨架和研究设计可以直接用，文献必须自己去知网核实。

## 三、界面上的几件事

- **生成数量**：滑块 5–15，硬性下限是 5 个（少于 5 个会提示）。
- **高级选项**：指定"必须用到的方法"和"必须包含的关键词"时，每个题目都会真的用上。
- **随机种子**：填一个数字，同参数下可复现同一批题目。
- **单题替换**：卡片底部「换一个」只换该题，不影响其他题目。
- **导出**：`exports\` 目录下生成 Markdown（含免责声明），可直接粘进开题报告。
- **快捷键**：`Ctrl+Enter` 生成，`Esc` 关闭弹窗。

## 四、配置项（`.env`）

首次运行会自动生成 `.env`。完整模板见 `.env.example`。

```ini
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=
LLM_MODEL=deepseek-chat
LLM_TEMPERATURE=1.0     # 选题是创造性任务，温度高一点题目更多样
LLM_MAX_TOKENS=8000     # 一次出 8 个带简报的题目，别低于 6000
LLM_TIMEOUT=180
LLM_JSON_MODE=1         # 个别服务商不支持 JSON 输出时改成 0
```

配置优先级：内置默认值 < 借用邻居项目 < `.env` < 环境变量 < 命令行参数。

## 五、目录结构

```
thesis-topic-helper\
├─ run.cmd / run.ps1        启动脚本（把 _boot 挂到 PYTHONPATH）
├─ app.py                   命令行入口（web / gen / offline / disciplines / doctor）
├─ web\index.html           网页界面（单文件，无构建、无 CDN、可离线）
├─ core\
│  ├─ config.py             配置解析与邻居项目 Key 借用
│  ├─ llm.py                大模型客户端（流式 + 重试 + 容错 JSON 提取）
│  ├─ prompts.py            提示词与输出结构约束
│  ├─ validate.py           结果归一化（模型乱写也不会白屏）
│  ├─ offline.py            内置学科知识库与离线组题引擎
│  ├─ generate.py           生成流水线（分批 / 补数 / 去重）
│  ├─ export.py             Markdown 导出
│  └─ server.py             本地 Web 服务 + SSE（标准库实现）
├─ tools\smoke_test.py      核心逻辑自检（不联网、不花钱）
├─ exports\                 导出的 Markdown
└─ _boot\sitecustomize.py   沙箱内临时目录修复
```

**零第三方依赖**：全部走 Python 标准库（`urllib` / `http.server`），
不需要 pip install，复制到任何装了 Python 3.9+ 的机器上都能跑。

## 八、已知限制（请务必知道）

1. **文献可能不真实**。大模型会编造看起来很像真的参考文献。系统把把握不足的条目标成
   「待核实」，但最终必须用知网 / 万方 / 维普 / Web of Science 核对原文再引用。
2. **题目需要人工筛选**。生成的是"值得考虑的候选"，不是"最终选题"，
   请结合导师方向、数据可得性和自己的兴趣定稿。
3. **离线模式的文献是占位引用**，只用于演示结构，不要照抄。
4. 生成 10 个以上带简报的题目会调用较长输出，按 DeepSeek 价格大约几分钱一次。
